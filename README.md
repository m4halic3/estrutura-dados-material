# Material de Estrutura de Dados

Repositório central que reúne material de apoio para o estudo de Estrutura de Dados, organizado por tópico. Cada tópico tem seu próprio repositório vinculado, com explicações e código comentado, pensado para quem está com dificuldade em compreender os conceitos.

O conteúdo é publicado como site em: https://m4halic3.github.io/estrutura-dados-material/

## Estrutura

- `index.md` — página inicial do site, com a lista de tópicos e links para os repositórios de conteúdo
- `_config.yml` — configuração do tema usado pelo GitHub Pages

## Contribuindo

Sugestões, correções e novos materiais são bem-vindos. Para contribuir:

1. Abra uma issue descrevendo a sugestão ou correção
2. Ou envie um pull request com a alteração proposta
